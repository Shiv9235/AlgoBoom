# DSA Tracker

A small React app for recording solved data-structures-and-algorithms problems and seeing practice progress at a glance.

## Build plan

1. Establish the React screen and a truthful empty state.
2. Add a controlled form for one problem.
3. Store submitted problems in React state and render the list.
4. Add filters and derived solved totals.
5. Persist the list in `localStorage`.
6. Polish, test the main flows, deploy, and document the project.

## Run locally

```bash
npm install
npm run dev
```
